# Adaptive Security Gateway

AI-based security gateway for detecting SQL Injection and XSS attacks in web requests.

## Project Status

🚧 Under Development

## Planned Features

- Deep learning SQLi and XSS payload detection
- Request parsing and preprocessing pipeline
- Threat intelligence, session and device profiling
- Behavioral anomaly scoring and risk-based decisioning
- Policy enforcement (ALLOW / MONITOR / RATE_LIMIT / BLOCK)
- Incident logging and analytics
- SOC dashboard for incident review and verdict override

## Tech Stack

- Python
- Flask
- PyTorch (CUDA)
- React
- Node.js
- MongoDB / PostgreSQL
