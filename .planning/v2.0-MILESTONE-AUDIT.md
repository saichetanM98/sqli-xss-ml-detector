## 2. Cross-Phase & End-to-End Integration Check
- **Data $\to$ Model**: Character vocabulary dictionary (`ml/artifacts/vocab.json`, 170 tokens) and trained weights (`ml/artifacts/best_model.pt`) seamlessly loaded by the live inference engine.
- **Ingress $\to$ Preprocessor $\to$ Detection**: Raw requests (including query params, JSON bodies, and headers) are extracted by `gateway/pipeline/parser.py`, normalized through `gateway/pipeline/preprocess.py`, and classified by `gateway/pipeline/detection.py` in under 2ms.
- **Detection $\to$ Risk & Policy**: High confidence SQLi / XSS detections trigger `BLOCK` verdicts and HTTP 403 status codes; benign requests trigger `ALLOW` verdicts and HTTP 200 status codes.
- **Policy $\to$ Incidents**: Blocked attacks are recorded into the security incident store with unique UUIDs and timestamps.
- **Repo-Wide Verification**: All 38 tests (`gateway/tests/` + `ml/tests/`) pass cleanly in 3.36s.
